Installation
============

``partipy`` requires Python version >= 3.10 to run.

Stable Version
--------------

Install the latest stable release from PyPI using pip:

.. code-block:: bash

   pip install partipy

Development Version
-------------------

To install the newest development version directly from GitHub:

.. code-block:: bash

   pip install git+https://github.com/saezlab/partipy.git
